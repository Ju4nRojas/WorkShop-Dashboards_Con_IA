# Kit completo · Misiones avanzadas de dashboards con IA

> **Extensión.** El taller de 30 minutos usa `kit-taller-30min`. Este kit completo trae las cuatro misiones (A–D), más datos y una rúbrica para quien quiera seguir después.

Datos abiertos reales de [datos.gov.co](https://www.datos.gov.co) (Ministerio de Minas y Energía, SICOM · licencia CC BY-SA 4.0 · corte octubre de 2026).

## Contenido
| Archivo | Para qué |
|---|---|
| `cuaderno.md` | **Empieza aquí.** Las 3 fases del taller, las 4 misiones, la lista de verificación y la rúbrica |
| `prompt-maestro.md` | El prompt que pegas al inicio de tu chat (reglas de cálculo, límites y formato) |
| `plantilla-pregunta.md` | Una página para convertir una necesidad en una pregunta verificable |
| `diccionario-datos.md` | Qué contiene cada CSV y sus trampas conocidas |
| `skill/dashboard-combustibles/` | Las mismas reglas empaquetadas como **skill** (Ruta 2) |
| `datos/` | Las tablas agregadas por mes (CSV, UTF-8) |

## Cómo empezar (3 pasos)
1. Elige tu ruta: **1** chat con archivos (sirve a todos) · **2** chat + skill · **3** agente con código (opcional).
2. Abre un chat nuevo, sube el CSV de tu misión y pega el **prompt maestro**.
3. Sigue el `cuaderno.md`. Todo número se compara con el control del facilitador.

## Ruta 2 · usar la skill
La carpeta `skill/dashboard-combustibles/` contiene un `SKILL.md`. Súbela en la sección de skills de tu herramienta (el nombre de la opción cambia según la herramienta y el plan: busca "Skills" o "Capacidades" en la configuración). Con la skill instalada, tu prompt solo necesita la misión. Si tu herramienta no admite skills, usa la Ruta 1: es el mismo contenido.

## Reglas del juego
- **Solo datos abiertos.** No subas datos internos ni confidenciales a una cuenta personal.
- Una cifra sin cálculo visible no se publica.
- Si los datos no pueden responder algo, la respuesta correcta es "no se puede con estos datos".
